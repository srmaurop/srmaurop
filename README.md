## Sobre mí

Desarrollo software a medida para pequeños negocios y oficinas.

Hago sistemas de punto de venta, catálogos web, control de trámites, recibos, préstamos y cobros, adaptados a la forma de trabajar de cada negocio.

Uno de ellos está en producción en un despacho legal, donde automatiza los recibos, genera reportes y lleva la gestión diaria de la oficina. Si tu negocio necesita algo parecido, escríbeme.

## Proyectos

| Proyecto | Qué hace | Stack |
|---|---|---|
| **Sistema POS para comercios** | Una misma base para tiendas de ropa, maquillaje y perfumes. App de escritorio para caja y administración, catálogo web para pedidos y pantalla en vivo (Dual Display) para que el cliente vea su compra. Presentado en una feria de proyectos. | VB.NET, PHP, MySQL |
| **Sistema para despacho legal** | Ingresos, recibos automáticos, trámites y expedientes de clientes, reportes y tarjetas de indicadores. En uso diario en la oficina. | VB.NET, Access |
| **Gestión de biblioteca** | Libros, préstamos, auditorías, gráficos y horarios. | VB.NET, Access |
| **Sistema de préstamos y cobros** | App web para celular y PC para llevar préstamos y cobranza. | PHP, JavaScript, MariaDB |

Los sistemas de clientes, como el del despacho legal, no tienen el código público.

## Qué puedo hacer por tu negocio

- Caja y catálogo web para tiendas, con pantalla en vivo para que el cliente vea su compra.
- Control de trámites, expedientes y recibos automáticos para oficinas.
- Control de préstamos y cobros desde el celular o la computadora.
- Adaptar un sistema a la forma de trabajar de tu negocio.
